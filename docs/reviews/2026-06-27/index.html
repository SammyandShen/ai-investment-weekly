02 本周真正重要的 5 件事

事件 #1 · ORCL本周−19%：2001年以来最差单周，AI融资危机警报拉响

事实

Oracle(ORCL)本周下跌约19%（峰值$303.62→本周收盘$148.68），为2001年8月以来最大单周跌幅。FY2026 CapEx同比+162%至$55.7B；负自由现金流约−$24B；总债务约$130B；合同积压$638B。FY2027 CapEx指引约$95B（额外增长~70%）。

来源 + 日期

CNBC，2026-06-26；Zacks，2026-06-26；Zacks，2026-06-25

为什么重要

ORCL是AI基础设施"先烧钱后收入"模式的最极端代表。$24B负FCF+$130B债务=融资危机风险。此逻辑若蔓延至其他AI capex大玩家（SMCI/CoreWeave等），信用利差将扩大。$638B积压虽长期利好，但短期资产负债表承压的定价已更像2000年Cisco。

影响方向

利空（AI硬件/基础设施板块）；中性（AI软件）

是否改变交易计划

是——ORCL止损（$188.1）在2-3周前已触发，若尚未执行，下周一立即清仓，不等反弹。

事件 #2 · MU Q3 FY2026大超预期：EPS $25.11 vs 估值$20.49，营收$41.5B vs $35.7B

事实

Micron于6/24盘后发布Q3 FY2026：EPS $25.11（vs 共识 $20.49，+22% beat）；营收 $41.5B（vs 共识 $35.7B，+16% beat）。盘后涨+13.1%至$1,185.90。SK Hynix + Micron HBM产能全部售罄至2027年，AWS P6-B200/B300需求持续强劲。

来源 + 日期

日内盘前简报（本站），2026-06-25；Investing.com，2026-06-26

为什么重要

这是本周唯一明确的AI需求确认信号。超预期幅度达历史前10%，证明HBM超级周期仍处加速阶段，驳斥了"AI capex过热但需求不足"的空方论点。对MRVL（光互联）、LITE（光模块）等上游供应链是结构性利多。

影响方向

利多（AI内存/光互联供应链）

是否改变交易计划

部分是——MRVL继续持有，止损上调至$250；LITE的止损暂不主动止损，等周一开盘确认是否守住$820。

事件 #3 · OpenAI + Broadcom揭晓Jalapeño推理芯片：推理成本降低50%，TSMC 3nm

事实

6/24，OpenAI与Broadcom联合发布首款自研推理芯片"Jalapeño"。关键指标：推理成本vs当前主流AI GPU降低约50%；采用TSMC 3nm工艺；2026年底开始在Microsoft数据中心部署。Broadcom CEO Hock Tan称AI芯片收入指引>$100B FY2027。

来源 + 日期

TechCrunch，2026-06-24；CNBC，2026-06-24；MACGPU Blog，2026-06-25

为什么重要

每家大型AI公司都在绕开NVDA建设自己的定制硅——OpenAI/Google TPU/AWS Trainium/微软Maia/特斯拉Dojo。Jalapeño是最高知名度的案例。短期：AVGO是最大受益者（设计+制造合作）；中期：推理成本下降50%会通过Jevons悖论推升总算力消耗（利多整个供应链）；长期：NVDA在推理端的垄断溢价受压。

影响方向

利多（AVGO/TSMC）；中性偏空（NVDA长期推理侧）；中性（整体需求）

是否改变交易计划

否——不影响当前持仓（无AVGO/TSMC直接仓位）。但下次新建AI硬件仓时，AVGO应优先于NVDA考虑。

事件 #4 · AWS GPU实例价格7/1起+20%：HBM3E短缺成本转嫁，P6-B300达$14.04/hr

事实

Amazon AWS宣布EC2 GPU Capacity Block预留实例价格7月1日起上涨约20%：P6-B300（Blackwell 300）$14.04/hr（+20%），P6-B200 $12.355/hr，P5（US）$5.191/hr。此前1月已悄然上调15%。原因：SK Hynix + Micron HBM3E 2026年产能全部售罄；B200 GPU需要192GB HBM3E（H100的2.4×）。

来源 + 日期

Investing.com，2026-06-26；Business Insider，2026-06-26

为什么重要

今年内累计+38%（1月+15%，7月+20%）的价格涨幅证明：①AI算力需求弹性极低（企业仍在买单）；②云厂商有pricing power→利好AMZN/MSFT云业务毛利率；③HBM成本通过完整供应链传导，内存供应链（MU/SK Hynix）护城河确认。潜在风险：若中小企业因成本而降速，2H26企业AI需求可能边际收缩。

影响方向

利多（AMZN/MSFT云毛利；MU/内存供应链）；中性偏空（AI中小企业客户需求短期）

是否改变交易计划

是（新信号）——支持建立MSFT/AMZN等AI软件/云仓位，作为替代ORCL/NOK清仓后的资金去向。

事件 #5 · OpenAI IPO延至2027（Barrons）：AI基础设施股拖累，私募估值悬顶

事实

6/26，Barrons报道OpenAI倾向将IPO推至2027年。同日分析文章指出Anthropic营收同比增长约4倍，OpenAI与Anthropic之间存在"赶在AI热度顶峰前上市"的竞争。SpaceX已于6/12以$1.75T估值IPO（首日+19%至$161）。

来源 + 日期

Barrons，2026-06-26；247 Wall St.，2026-06-26

为什么重要

OpenAI IPO延迟直接打击以OCI/Stargate为抵押物估值的ORCL和CoreWeave。更深层含义：连OpenAI自己都对2026年估值持观望态度——意味着私募市场也在对AI泡沫重新定价。Anthropic 4x收入增长的竞争压力倒逼两家公司可能在2026底/2027冲刺上市，届时将提供>$3T私募估值的公开市场供给冲击。

影响方向

利空（ORCL/CoreWeave/AI基础设施）；中性（整体NVDA/AVGO）；远期利空（IPO窗口打开时的流动性冲击）

是否改变交易计划

是——进一步确认ORCL止损须立即执行，不建议等待反弹再出；加剧了"2000Q1→2000H2"的风险路径。
