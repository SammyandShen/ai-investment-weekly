⬢ 研究框架

产业链周报 · 转折点的定义

本周报中的"转折点"必须满足以下条件中的多数：

  1. 新 AI 能力出现，使新硬件 / 软件 / 数据 / 能源 / 网络 / 存储 / 设备 / 服务需求从可选变成刚性。
  2. AI 产业链的核心瓶颈发生迁移（训练→推理、GPU→HBM、HBM→网络、网络→电力、云端→端侧、数字→物理）。
  3. 真实购买方开始付钱，资本开支 / 订单 / 价格 / 交期 / 库存 / 产能利用率有可观测变化。
  4. 受益公司未来收入、利润率、自由现金流或估值逻辑可能发生变化。
  5. 市场尚未充分定价（股价、估值、盈利预测、IV、持仓、新闻热度）。
  6. 存在可交易资产，且流动性足够。
