⬢ 研究框架

产业链周报 · 转折点的定义

本周报中的"转折点"必须满足以下条件中的多数：

  1. 新 AI 能力出现，使新硬件 / 软件 / 数据 / 能源 / 网络 / 存储 / 设备 / 服务需求从可选变成刚性。
  2. AI 产业链的核心瓶颈发生迁移（训练→推理、GPU→HBM、HBM→网络、网络→电力、云端→端侧、数字→物理）。
  3. 真实购买方开始付钱，资本开支 / 订单 / 价格 / 交期 / 库存 / 产能利用率有可观测变化。
  4. 受益公司未来收入、利润率、自由现金流或估值逻辑可能发生变化。
  5. 市场尚未充分定价（股价、估值、盈利预测、IV、持仓、新闻热度）。
  6. 存在可交易资产，且流动性足够。

市场周度复盘 · 七段固定结构

  1. 本周总判断（市场状态 + AI 泡沫阶段概率分布 + 一句话结论）
  2. 本周真正重要的 5 件事
  3. 泡沫评分模型（11 维度 × 5 分 = 55 分；vs 上周变化；最像哪一年；反证条件）
  4. 我的持仓周度处理（读 data/portfolio.json）
  5. 下周三种情景计划（继续上涨 / 顶部震荡 / 下跌或破裂）
  6. 下周交易行动清单（最多 8 条，每条含触发/失效/时间周期）
  7. 下周必须盯的转折点（最多 10 条）

硬性要求（两类产出都适用）

  • 不允许编造数据。所有关键事实必须标注来源 + 发布日期。
  • 不允许只给概念股清单 / 只讲宏大叙事 / 把"AI 相关"等同于"值得买"。
  • 每个交易建议必须有触发条件、失效条件、时间周期。
  • 没有明确机会时直接说"没有明确交易机会"，并说明缺什么数据。
  • 事实 / 推论 / 概率情景 / 行动建议必须分开标注。

本网站非投资建议，仅为研究框架与公开数据汇总。所有报告中的"上行空间"和"概率情景"均为情景分析，不构成对未来回报的精确预测。
