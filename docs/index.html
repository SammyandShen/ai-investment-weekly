∞ 这是什么

每周一份独立、自洽、可阅读的研究简报。每期围绕同一套框架展开：

  • 找新能力 — 最近 30 / 90 / 180 天 AI 模型、产品、芯片、机器人、医药、端侧设备的新进展。
  • 找新瓶颈 — 这些新能力会消耗什么（算力、内存、存储、网络、电力、散热、传感器、机械部件、数据、实验室能力、制造能力、认证能力）。
  • 找付费方 — 谁必须付钱，区分真实买家、概念受益者、间接受益者。
  • 找供需变化 — 订单、价格、交期、库存、产能、资本开支、管理层指引的硬数据。
  • 找利润池 — 哪个环节有定价权、稀缺产能、客户认证、技术壁垒。
  • 找市场预期差 — 股价、估值、EPS 预测、机构持仓、新闻热度。
  • 找交易表达 — 多 / 空 / 配对 / 期权 / ETF / 跨市场传导 / 观察。

每个机会按 100 分制评分。≥80 重点交易候选；65–79 观察 / 试错；<65 暂时无明确交易价值。

⬢ 研究框架

转折点的定义

本周报中的"转折点"必须满足以下条件中的多数：

  1. 新 AI 能力出现，使新硬件 / 软件 / 数据 / 能源 / 网络 / 存储 / 设备 / 服务需求从可选变成刚性。
  2. AI 产业链的核心瓶颈发生迁移（训练→推理、GPU→HBM、HBM→网络、网络→电力、云端→端侧、数字→物理）。
  3. 真实购买方开始付钱，资本开支 / 订单 / 价格 / 交期 / 库存 / 产能利用率有可观测变化。
  4. 受益公司未来收入、利润率、自由现金流或估值逻辑可能发生变化。
  5. 市场尚未充分定价（股价、估值、盈利预测、IV、持仓、新闻热度）。
  6. 存在可交易资产，且流动性足够。

硬性要求

  • 不允许编造数据。
  • 不允许只给概念股清单。
  • 不允许只讲宏大叙事。

  • 推测必须标注"推测"或"情景分析"。
  • 没有明确交易机会时直接说没有，并说明缺什么数据。

本网站非投资建议，仅为研究框架与公开数据汇总。所有报告中的"上行空间"为情景分析，不构成对未来回报的精确预测。
