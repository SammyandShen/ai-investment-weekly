04 今日单条最重要看点

GOOGL Q2 盘后财报（约 16:30 ET）是本周乃至整个七巨头财报季的定调时刻。若 Cloud 营收增速超 30%（共识约 28–29%）且 AI 搜索货币化有正向表述，NDX 短线有望向上突破 29,500；反之若 Cloud 减速或 CapEx 指引远超预期，则 AI 估值再次受压。关键数字：Google Cloud 营收（共识 ~$14B）和运营利润率（共识 ~31%）。今日收盘前市场很可能处于等待模式，波动率主要集中在盘后。
