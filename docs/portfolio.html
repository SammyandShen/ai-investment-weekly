怎么把网页修改同步到文件 / 跨设备使用

这个网页只在你的浏览器本地保存（localStorage），不会自动写到磁盘。同步流程：

  1. 在网页上编辑持仓与观察清单
  2. 点 导出 JSON，浏览器会下载 portfolio.json
  3. 把下载的文件覆盖项目里的 data/portfolio.json
  4. cd ~/ai-investment-weekly && git add data/portfolio.json && git commit -m "Update portfolio" && git push

第一次使用、或换浏览器/设备时，可以点 导入 JSON 把当前 data/portfolio.json 的内容粘贴进来。

隐私：持仓数据保存在你的本地浏览器和本地仓库，不会被 GitHub Pages 公开（data/ 目录不在 docs/ 下，不被网站服务）。
