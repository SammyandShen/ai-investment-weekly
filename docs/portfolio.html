怎么用 / 隐私保证

首次使用：

  1. 点页面底部 选择 data 目录，浏览器弹窗里定位到 ~/ai-investment-weekly/data/ 并选中。
  2. 授权后，网页会读取该目录下的 portfolio.json（不存在就用空模板）。
  3. 编辑表格 → 点 保存到文件，浏览器直接写到本地 portfolio.json。
  4. 完。skill 在周六 10:00 自动读这个文件。

之后每次：浏览器记住了目录授权，但每次新会话需要点一次"验证权限"（浏览器安全要求）。

隐私保证：

  • data/portfolio.json 已加入 .gitignore，永远不会进 git，永远不会上 GitHub。
  • 浏览器写文件用的是 File System Access API，数据从浏览器直达本地磁盘，不经过任何服务器。
  • 仓库本身可以放心保持 public — 真实持仓只存在你本地。

不支持 FS Access API 的浏览器（Safari、Firefox）：降级到下方"导出 JSON"，需要手动覆盖文件。Chrome / Edge / Arc / Brave 都支持。
